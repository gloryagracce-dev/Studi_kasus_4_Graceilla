PENJELASAN CODENPROGRAM :

1. Membuat Dictionary

   Saya membuat variabel bernama buku yang berisi data awal:

   -Judul

   -Penulis

   -Tahun terbit

   Setiap keterangan disimpan berpasangan kunci : nilai.

2. Perulangan

   while True

   Supaya menu bisa dipilih berulang-ulang tanpa berhenti. Program akan terus berjalan sampai pengguna memiliki nomor 5 untuk keluar.

3. Menampilkan Menu

   Setiap kali perulangan berjalan, daftar pilihan ditampilkan. pengguna diminta untuk mengetik nomor yang diinginkan.

4. Pilihan 1 - Tampilkan Data

   Menggunhnakan items() supaya bisa membaca nama keterangan serta isinya satu per satu, lalu ditampilkan ke layar.

   Pilihhan 2 - Tambah Penerbit

   Menambahkan kunci baru yaitu penerbit ke dalam dictionary. Program mengecek dulu apakah belum ada, supaya ganda.

   Pilihan 3 - Ubah Penulis

   Mengganti isi bagian penulis dengan nama yang mau diganti pengguna. Isi nama langsung tertimpa dengan yang baru.

   Pilihan 4 - Hapus Penerbit

   Menggunakan perintah del untuk menghapus bagian penerbit dari dictionary. Ada pengecekan agar tidak error kalau datanya belum ada.

   Pilihan 5 - Keluar & Tampilkan Hasil Akhir

   Sebelum berhenti, seluruh data buku yang sudah diubah ditampilkan sekali lagi. Lalu perintah break menghentikan perulangan dan program selesai.
